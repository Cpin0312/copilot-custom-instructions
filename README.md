# Copilot カスタム指示

Microsoft 365 Copilot に貼る「カスタム指示」の文です。Copilot が、結論を先に短く答え、推測で埋めず、送信や削除の前に確認を取るようにします。

- 本文：[custom-instructions.md](custom-instructions.md)（そのままコピーして貼れます）
- ブラウザで読む・コピーする：GitHub Pages のページ（下の「使い方」）

## 貼る場所

Copilot の設定 →「パーソナライズ」→「カスタム指示」

※ この画面の名前は**未確認**です。会社の管理者が切っていると、この項目は出ません。

## 使い方

1. ページを開き、「コピー」を押す（または custom-instructions.md の本文を全部コピーする）
2. Copilot の「カスタム指示」の欄に貼って、保存する
3. 新しい会話から効きます
