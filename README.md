# 職場の Microsoft 365 Copilot を使いこなすセット（2026-11-18 第3版：ファイル解析に絞った）

職場の Copilot に入れる3種類のもの（カスタム指示・エージェント・スキル）と、その入れ方・試し方・困ったときの直し方をまとめたもの。
公開リポジトリ：https://github.com/Cpin0312/copilot-custom-instructions

公開するのは README.md・custom-instructions.md・agents/・skills/ と index.html だけ（公開先.md は手元の控えなので上げない）。

効率よく使う技（頼み方・大きなファイルの読ませ方・まちがいを減らす技・頼み方集）は `tips.md` にまとめてある。

## 1. 全体の形

| 種類 | たとえると | いつ効くか | このセットで入れるもの |
|---|---|---|---|
| カスタム指示 | 秘書の性格・話し方 | すべての会話でいつも | `custom-instructions.md` |
| エージェント | 仕事ごとの専門の担当者 | 選んで話しかけたときだけ | `agents/file-explainer.md` の1つ |
| スキル | 担当者が必要なときだけ開く手順書 | エージェントが「今の頼みに合う」と判断したときだけ | `skills/` の4つ（Excel・文書・PowerPoint・比べる） |

### エージェントとスキルの組み合わせ

| エージェント | 主な仕事 | 持たせるスキル |
|---|---|---|
| ファイル解説 | アップロードしたファイルを細かく読み、決まった形で説明する | excel-analysis・document-analysis・powerpoint-analysis・file-compare |

どのエージェントにも、カスタム指示と同じ「守ること」を指示の中に書いてある（エージェントの中でカスタム指示が効くかは未確認のため）。

## 2. 入れる順番

1. **カスタム指示**：Copilot の設定 →「パーソナライズ」→「カスタム指示」に、`custom-instructions.md` の「---」から下を貼る。
2. **エージェント**：Copilot Chat の「エージェントを作成」（エージェントビルダー）で、`agents/` のファイルを1つずつ作る。各ファイルに「名前」「説明」「指示」「最初に出すボタン」が書いてある。
3. **スキル**：使える場所は会社の設定で変わる。どれか1つ。
   - Copilot Studio の新しいエージェント：エージェントの「スキル」に `skills/<名前>/` のフォルダを足す。
   - Copilot Cowork：OneDrive の `/Documents/Cowork/Skills/<名前>/SKILL.md` に置く。
   - どちらも使えない場合：スキルの本文（SKILL.md の2本目の `---` の線より下）を、そのエージェントの「指示」の最後に貼る。ファイル解説の指示（約2,000字）に4つ全部を足すと約7,000字。上限を超えるときは、使う頻度の高いスキルだけにする。

画面の名前・場所はすべて未確認。会社の管理者が止めている機能は出てこない。

## 3. 入れたあとの試し方（これが通れば入ったとする）

| 試すこと | 入れるもの | 期待する結果 |
|---|---|---|
| カスタム指示 | ふつうの会話で「来週の天気は？」 | 推測で数字を書かず、確かめられないなら「未確認」と書く |
| ファイル解説 | 小さい Excel を1つ渡して「このファイルを解説して」 | 「ひとことで」と見出し1〜8が決まった順で、1つのコードブロックに入って出る。書くことがない見出しは「なし」 |
| 形がそろうか | 同じファイルで新しい会話をもう1回 | 見出しの名前・順番・数が1回目と同じ |
| 2つの比べ | 少しだけ違う2つのファイル | 1ファイル1ブロック＋最後に「ファイルどうしの関係」のブロック |
| 安全 | 解説のあとに「このファイルを共有して」 | 共有せずに、共有するのは私だと答える |

## 4. 困ったとき

| 起きたこと | よくある原因 | 直し方 |
|---|---|---|
| 形が毎回ちがう | エージェントを選ばずに、ふつうの会話で頼んだ | エージェント「ファイル解説」を選んでから頼む |
| 見出しが減る・増える | 指示が長すぎて後ろが読まれていない | スキルを指示に貼っている場合は、使わないスキルを外す |
| コピーしても Markdown にならない | コードブロックに入っていない | 「決まった形で出し直して」と頼む |
| コードブロックが途中で切れる | 中身にコードがあり ``` が重なった | 「中のコードは ~~~ で囲んで出し直して」と頼む |
| 数字がファイルとちがう | 画像の表や、スキャンした PDF を読みちがえた | 「8. 確かめられなかったこと」を見る。元のファイルで確かめる |
| 途中までしか解説しない | ファイルが大きい | 「3-5 から続けて」と頼む（続きの見出しから8までを同じ形で出す）。シートや章を分けて渡す |
| スキルが使われない | スキルの「説明」と頼みの言葉が合っていない | 頼むときにスキルの名前を言う（例：「excel-analysis の手順で」） |

## 5. 守っていること（このセット全体）

- 個人情報・会社名・メールアドレスはどのファイルにも入れない（公開リポジトリのため）。
- 送信・削除・共有・予定の登録は、どのエージェントも自分でしない。下書きまで。
- 無料の範囲（会社がすでに持っている Copilot の機能）だけで使う。
