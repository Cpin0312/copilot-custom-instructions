# メールの返事の下書きの手順

## 使う場面
- 「返事を作って」「返信の下書き」「断りのメールを」「お礼を返したい」と頼まれたとき。

## 手順
1. **何を返すかを決める。** 相手のメールが求めていること（質問・依頼・確認・お知らせ）を1つずつ並べる。返事でそれぞれに答える。答えられないもの（私が決めること）は〈　〉で空けておく。
2. **丁寧さを決める。**
   - 社外・目上・はじめての相手 → ていねい（「お世話になっております」「よろしくお願いいたします」）
   - 社内のふだんの相手 → ふつうのていねい（「お疲れさまです」）
   - 相手のメールの丁寧さより、くだけた書き方にしない
   - 私が「くだけて」「短く」と言ったときは、それに従う
3. **組み立てる。** 次の順にする。
   1. あいさつ（1行）
   2. 何のメールへの返事か（1行。「〇〇の件、ありがとうございます」）
   3. 答え（相手が求めたことに、ひとつずつ）
   4. こちらからのお願い・次にすること（あれば）
   5. 結び（1行）
   6. 署名は書かない（私の署名が自動で入るため）。
4. **件名は「Re: 元の件名」にする。** 元の件名を変えない。
5. **宛先を確かめる。** 元のメールに CC があるとき、「全員に返信」にするかどうかを「5. 確かめてほしいこと」に書く。

## 決まり（これを破ると困る）
- メールにない事実・約束・日付・金額を書かない。必要なら〈　〉で空ける。
- 「承知しました」「対応します」など引き受ける言葉は、私が引き受けると言ったときだけ書く。分からないときは「確認して、改めてご連絡します」にして、「5」に書く。
- 断るときは、理由を勝手に作らない。理由を私が言っていなければ〈理由〉と空ける。
- 社外の人への返事に、社内の人の名前・社内の事情・個人情報を入れない。
- 1つの返事は、長くても画面1つ分（目安 400 字）に収める。長くなるときは、要点だけにして「詳しくは別途」とする前に、私に聞く。

## 出す前の確かめ
- 相手が求めたことに、全部答えたか（答えないものは〈　〉で空けたか）。
- メールにない約束が入っていないか。
- 件名が「Re: 元の件名」か。

## しないこと
- 送信・転送・下書きフォルダへの保存。頼まれても、送るのは私だと伝える。
