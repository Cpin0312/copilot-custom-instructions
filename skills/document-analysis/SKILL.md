# Word・PDF の解説の手順

## 使う場面
- Word・PDF・テキストの文書を渡されて「解説して」「何が書いてある？」「私は何をすればいい？」と頼まれたとき。

## 手順
1. **文書の種類を決める。** 報告書・手順書・規程・契約書・案内・申請書・議事録など。「1. このファイルは何か」に書く。どれにも当たらなければ、見たままを書く。
2. **章立てをそのまま使う。** 「3. 中身の解説」の小見出し（3-1, 3-2 …）は、文書の章・見出しの順にそろえる。見出しのない文書は、話の切れ目ごとに区切り、自分でつけた見出しには「（区切りは解説者）」と添える。
3. **章ごとに書く。** 何が書いてあるか → それは私にとって何を意味するか、の順で、1章につき2〜4文。
4. **期限・義務・条件を抜き出す。** 「〜まで」「〜しなければならない」「〜の場合は」「〜を除く」の文を探し、
   - 期限と、私がすること → 「7. 私がすること」
   - 日付・金額・人数・名前 → 「4. 数字・日付・名前」（ページと章を添える）
5. **食いちがいを探す。** 次を「6. 注意点」に書く：
   - 同じことが2か所でちがって書かれている
   - 日付と曜日が合わない
   - 合計が合わない
   - 「別紙」「添付」とあるのに、その中身が付いていない
   - 版や日付が古い
6. **言葉を説明する。** 専門用語・社内用語・法律の言い回しを「5. 分かりにくい言葉」に、やさしい言葉で書く。

## 文書の種類ごとに見ること
- **契約書・規程：** 期間、解約・変更の条件、禁止されていること、守らなかったときのこと、誰の責任か。条番号を必ず添える。法律上どうなるかの判断はしない（「（考え）」としても書かない）。必要なら「専門の人に確かめる」と「7」に書く。
- **手順書：** 手順を番号つきで写し、抜けている手順・順番が変な所を注意点に書く。
- **申請書・様式：** 書く欄の一覧と、それぞれに何を書くかを「7」に書く。
- **案内・お知らせ：** 日時・場所・持ち物・申し込みの期限。

## 気をつけること（よくある失敗）
- スキャンした PDF は文字が画像になっている。読み取った文字には「（画像から読み取り）」と添え、数字は特に注意点に「元で確かめて」と書く。
- ページ数が多い（目安 30 ページより多い）ときは、読めた範囲を「8」に書く。目次がある文書は、目次で全体を示してから中身に入る。
- 表は崩さずに Markdown の表にする。崩れそうな大きな表は、要点だけを書き、「元の表を見て」と添える。
- 脚注・注釈・小さな文字（但し書き）にこそ条件が書いてある。読み落とさない。

## 出す前の確かめ
- 3 の小見出しの順が、文書の章の順と同じか。
- 7 の期限は、文書の文と一字一句同じか。ページと章を添えたか。
- ファイルにないことを事実として書いていないか。

## できないとき
- パスワード・壊れたファイル：決まった形を出さず、そのことだけを1文で伝える。
- 文字が読めない画像だけの PDF：読めたところまでを解説し、「8」に書く。
