# Excel・CSV の解説の手順

## 使う場面
- Excel や CSV を渡されて「解説して」「中身を教えて」「おかしい所はある？」と頼まれたとき。

## 手順
1. **全体を数える。** シートの数と名前を、左から順に一覧にする。隠しシートがあれば「（隠し）」と書く。CSV は1シートとして扱う。
2. **シートごとに表を見つける。** 1枚のシートに表が2つ以上あることがある。表ごとに、見出しの行・データの範囲（例：A3:F120）・行数を書く。
3. **見出しの意味を書く。** 列ごとに「何の値か・単位」を書く。略語や社内の言葉は「5. 分かりにくい言葉」に入れる。意味が分からない列は、分からないと書く。
4. **数式を見る。** 数式があれば、何を計算しているかを言葉で書く（例：「G列＝E列×F列で金額」）。読めるのが値だけで数式が見えないときは、「数式は確かめられなかった」と書く。
5. **自分で確かめる。** 合計行・件数・平均がある表は、元のデータから計算し直す。計算し直した値を必ず書く（合っていても「計算し直して一致：〈値〉」と書く）。合わなければ「6. 注意点」に、ファイルの値と計算した値を両方書く。計算し直していないときは「計算していない」と書く。計算していないのに「合っている」と書かない。
6. **おかしい所を探す。** 次を「6. 注意点」に書く：
   - 空欄が多い列・行
   - 同じ行が2回ある（重複）
   - 数字の列に文字が混ざっている
   - 日付の書き方がばらばら・ありえない日付
   - 合計が合わない
   - #REF! #N/A #DIV/0! などのエラー
7. **大事な数字を抜き出す。** 合計・最大・最小・期限など、私の判断に使う数字を「4. 数字・日付・名前」に、セルの場所（シート名!セル）と一緒に書く。

## 気をつけること（よくある失敗）
- 表示の値と中の値がちがうことがある（四捨五入の表示・％表示）。表示のまま写し、ちがいがありそうなら注意点に書く。
- 結合セルは、いちばん左上のセルにだけ値がある。下の行を「空欄」と数えない。
- 和暦・西暦・シリアル値（45000 など）の日付は、元の形のまま写し、日付に直した値を（　）で添える。
- 行が多い（目安 1,000 行より多い）ときは、全部を書き写さない。件数・範囲・代表の数行・合計だけを書く。読み切れなかった範囲は「8」に書く。
- グラフ・図形・画像の中の文字は、読めた分だけ「（画像から読み取り）」と添える。
- マクロ（.xlsm）は中身を実行しない。あることだけを書く。

## 出す前の確かめ
- シートの数と、3 に書いたシートの数が同じか。
- 4 の数字にすべて場所（シート名!セル）が付いているか。
- 手順5 で計算し直した値を書いたか（していないなら「計算していない」と書いたか）。

## できないとき
- パスワード・壊れたファイル：決まった形を出さず、そのことだけを1文で伝える。
- 外のデータにつながる表（外部リンク・ピボットの元データがない）：見えている値だけで解説し、「8」に書く。
